What Section Writing Stats can show:

Live stats where you want them

Show live statistics beside Markdown headings, below the note title, or in the status bar, in both the editor and Reading view.

Words, characters, and reading time

See the measurement you want to track without leaving the note.

Choose what stays visible

Turn individual statistics on or off, use compact labels, and hide badges for short sections.

Set a writing target.

Add a Target: 750 words line below any heading. It stays plain Markdown, and in Live Preview it turns into a tidy chip.

A few useful answers.

Everything stays in your Markdown. The plugin adds live context while you write.

What counts as a section?

A heading includes everything beneath it, including nested headings, until the next heading at the same or a higher level.

Can I set a target for one part of a note?

Yes. Add a target line below a heading to track that section, or add one to the note for a whole-note target.

Can I choose where the statistics appear?

Yes. Show them beside headings, beside the note title, in the status bar, or only in the places you want.
